How a session works

Hit. Swap.
Compare. Decide.

Most players never get to feel the difference between two setups side by side. In a session, that’s the whole point.

String demosTension trialsLive feedbackSetup notes

  1. Baseline

    Warm up and hit with your current racquet and strings so we know where you’re starting from.

  2. Test

    Swap between demo racquets strung with different strings and tensions from the Stay Strung string library.

  3. Feedback

    Real-time coaching on how each setup changes your spin, control, power and comfort.

  4. Lock it in

    Leave with a recommended setup — and we’ll string it for you the same way every time.
